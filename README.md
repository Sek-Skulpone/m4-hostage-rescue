# ภารกิจช่วยตัวประกัน

เกมฝึกบวกจำนวนเต็ม แข่งกับเวลา — ไข 10 ด่านให้ครบภายใน 10 นาที ก่อนน้ำท่วมตัวประกัน

- นาฬิกานับถอยหลัง 10 นาที พร้อมระดับน้ำที่สูงขึ้นจริงตามเวลาที่เหลือ
- นักเรียนกรอกชื่อ ชั้น เลขที่ ก่อนเริ่มเล่น **ไม่ต้องมีบัญชีใดๆ**
- ผลการเล่นทุกครั้ง (ผ่าน/ไม่ผ่าน, ด่านที่ทำได้, เวลาที่ใช้) ถูกบันทึกอัตโนมัติ
- ครูกดปุ่ม **"ครูดูคะแนนย้อนหลัง"** ที่หน้าแรกของเกม เพื่อดูตารางผลย้อนหลังของทุกคน

## ฐานข้อมูล

ใช้ Firebase Realtime Database โปรเจกต์ `m4-interval-kahoot` (โปรเจกต์เดียวกับเกม [แข่งช่วง & อสมการ](https://github.com/Sek-Skulpone/m4-interval-kahoot)) แต่บันทึกข้อมูลไว้คนละ path (`hostage_scores`) จึงไม่ปนกับเกมอื่น — ตั้งค่าไว้เรียบร้อยแล้ว ไม่ต้องทำอะไรเพิ่ม
